# Gomuko-2 (C++, vs computer)

Gomoku (five in a row) in the C++ console where you play against the computer.

## How to play

You enter the board size and the win length, then take turns with the computer. The first to connect the win length in a row wins.

## Requirements

Windows is the safest choice. The code uses `conio.h`, which is not available in every compiler.

## Build

Open `gomuko1.sln` in Visual Studio and run it. You can also compile `gomuko1.cpp` with any C++ compiler that supports these headers.
